# FIT

**Қазақ тіліндегі Android фитнес күнделігі.** Жаттығуды таңдап, орындау барысын бақылаңыз және нәтижелеріңізді бір жерден көріңіз.

![FIT жаттығу санаттарының иллюстрациялары](docs/fit-artwork-contact.jpg)

- **12 жаттығу, 8 санат:** суретті каталог, атау бойынша іздеу және деңгей сүзгісі. Каталог интернетсіз де ашылады.
- **Жаттығу сессиясы:** тәсілдер, қайталаулар, орындалу нұсқаулығы және прогресс.
- **Жетістіктер:** апталық белсенділік, жаттығу тарихы және салмақ графигі.
- **Жеке профиль:** фитнес мақсаты, салмақ бірлігі және Firebase арқылы деректерді сақтау.

**Ноутбук ауыстырғанда немесе тазалағаннан кейін:** [Жобаны толық қалпына келтіру нұсқаулығы](RESTORE.md).

## Іске қосу

1. Репозиторийді жүктеп алып, Android Studio-да ашыңыз. Жобаға JDK 17 немесе одан жаңасы және Android SDK 36 қажет.
2. Қолданбаның ең төменгі нұсқасы — Android 8.0 (API 26). Firebase конфигурациясынсыз да debug APK құрастырып, каталогты қарай аласыз.
3. Кіру, тіркелу және бұлттық сақтау үшін өз Firebase жобаңызда `com.example.fit` Android қолданбасын тіркеңіз. `google-services.json` файлын жергілікті `app/` қалтасына салыңыз, Email/Password кіруін қосыңыз және [Firestore ережелерін](firestore.rules) жариялаңыз. [Толық нұсқаулық](README_FIREBASE.md).

Windows-та құрастыру және тексеру:

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

Дайын debug APK: `app/build/outputs/apk/debug/app-debug.apk`.
