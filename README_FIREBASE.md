# Подключение Firebase к FIT

> Бұрынғы аккаунт пен тарихты сақтау үшін сол Firebase жобасына қайта қосылыңыз: [қалпына келтіру нұсқаулығы](RESTORE.md#бұрынғы-firebase-ті-қайтару).

Конфигурация Firebase не включена: без настоящего `app/google-services.json` вход, регистрация и облачное сохранение недоступны. Каталог можно просматривать без аккаунта. Приложение не имитирует успешные операции.

1. Откройте https://console.firebase.google.com/ и создайте или выберите проект.
2. Добавьте Android-приложение с точным package/applicationId `com.example.fit`.
3. Скачайте **настоящий** `google-services.json`, положите в `app/google-services.json`. Не меняйте его содержимое вручную.
4. Authentication → Sign-in method → Email/Password → Enable. Сохраните настройку.
5. Firestore Database → Create database → Production mode. Выберите подходящий регион.
6. Firestore → Rules: скопируйте весь `firestore.rules` и нажмите Publish. Либо выполните `firebase deploy --only firestore:rules` после `firebase login` и `firebase use --add`.
7. Синхронизируйте Gradle и пересоберите приложение. Google Services применяется автоматически при наличии JSON; требуется новая сборка.
8. Создайте аккаунт в FIT. Проверьте пользователя в Authentication и документ `users/{uid}` в Firestore.
9. Завершите тренировку, добавьте вес, отредактируйте профиль. Убедитесь, что соответствующие документы созданы/обновлены.
10. Создайте второй аккаунт и проверьте изоляцию данных. В Rules Playground проверьте: неавторизованный доступ запрещён; чужой UID запрещён; запись лишних полей и неверных типов запрещена.

Пароли обрабатывает только Firebase Authentication; в Firestore они не передаются. Записи тренировок неизменяемые; ID сессии используется для безопасного повтора сохранения. Вес и текущий вес профиля обновляются одним batch-запросом. Требуется доступ к интернету для подтверждения сохранения. При ошибке или таймауте приложение не показывает успех.

Зависимости используют Firebase BoM и основные модули `firebase-auth` / `firebase-firestore`, без устаревших KTX-модулей: https://firebase.google.com/docs/android/setup.

Даты создания профиля, завершения тренировки и записи веса выставляет сервер Firestore. Для промышленной защиты от подделки длительности и спортивных результатов нужен доверенный сервер; текущие правила обеспечивают принадлежность, структуру и диапазоны данных.
